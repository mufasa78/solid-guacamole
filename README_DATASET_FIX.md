# 数据集格式修复工具

本项目包含多个工具，用于修复数据集格式，确保它们包含所需的 'text' 和 'label' 列。

## 问题背景

本系统要求所有数据集必须包含 'text' 和 'label' 列，其中：
- 'text' 列包含要分类的文本内容
- 'label' 列包含数字标签（0, 1, 2, ...）

如果您的数据集不符合这个格式，您可以使用以下工具进行修复。

## 可用工具

### 1. fix_all_datasets.py

这个脚本会自动修复 datasets 目录中的所有数据集。

使用方法：
```
py fix_all_datasets.py
```

脚本会：
1. 扫描 datasets 目录中的所有 CSV 文件
2. 检查每个文件是否有所需的 'text' 和 'label' 列
3. 如果没有，会创建一个修复版本（文件名后缀为 _fixed.csv）
4. 生成一个 HTML 报告，显示所有修复的数据集

### 2. fix_dataset_format.py

这个脚本可以修复单个数据集。

使用方法：
```
py fix_dataset_format.py 数据集路径 [输出路径]
```

例如：
```
py fix_dataset_format.py datasets/books.csv
```

如果不提供输出路径，脚本会创建一个名为 [原文件名]_fixed.csv 的文件。

### 3. 应用程序内自动修复

应用程序已经集成了数据集修复功能。当您上传或选择一个不符合格式要求的数据集时，应用程序会：
1. 提示您数据集格式错误
2. 自动尝试查找已修复的版本
3. 提供"自动修复数据集格式"按钮，让您可以直接在应用程序中修复数据集

## 修复逻辑

修复工具会尝试：
1. 查找可能包含文本内容的列（如 title, name, description 等）来创建 'text' 列
2. 查找可能包含标签信息的列（如 category, class, genre 等）来创建 'label' 列
3. 如果找不到合适的列，会使用行索引模 8 作为标签（0-7）

## 注意事项

- 修复后的数据集会保留原始数据集中的所有行
- 'label' 列会被转换为整数类型
- 如果原始数据集中的标签是文本形式，会创建一个映射文件（[文件名]_label_mapping.csv）
